# Acknowledgements

This project was developed as part of a blockchain course and builds upon several open-source tools, official documentation sources, and educational resources.

## Algorand Ecosystem

The blockchain infrastructure used in this project is provided by Algorand.

- Algorand Official Website: https://www.algorand.com
